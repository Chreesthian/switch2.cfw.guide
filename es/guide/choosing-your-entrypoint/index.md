# Elegir tu punto de entrada

Hay varios puntos de entrada disponibles para ejecutar homebrew en la Nintendo Switch 2. Esta guía cubrirá los dos más utilizados: **Civilization VII** y **SmileBasic 4**.

### Civilization VII

**Civilization VII** es un juego de Nintendo Switch que se puede usar como punto de entrada para homebrew. Este título es preferible porque está en formato de cartucho y no se puede parchear sin actualizarlo. Asegúrate de tener instalada la versión correcta (v1.0.0).

::: tip

Continúa con [Preparar CivSwitch](/es/guide/preparing-civswitch/)

:::

### SmileBasic 4

**SmileBasic 4** es otro título que se puede usar como punto de entrada para homebrew. Este juego solo está disponible en la eShop, y la versión correcta (v4.4.9) solo estuvo disponible durante unas horas antes de que Nintendo lo retirara de la tienda.

::: tip

Continúa con <Definition term="Preparar SmileBasic">¡En construcción!</Definition>

:::

### Otros títulos

También hay otros títulos compatibles con otros exploits, como Seedsow Lullaby y Balatro. Estos juegos tienen requisitos diferentes y actualmente no se tratan en esta guía.
